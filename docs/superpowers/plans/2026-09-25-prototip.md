# teknemisatıyorum.com Prototip — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tasarım belgesindeki ~45 ekranın tamamını, sahte verilerle, Expo üzerinde uçtan uca tıklanabilir hale getirmek.

**Architecture:** Expo Router ile dosya tabanlı sayfalar. Ekranlar veriye yalnızca `src/services` üzerinden erişir. Servis katmanı şimdilik, sahte veriyle beslenen bir zustand deposuna bağlı. Akıllı Asistan saf TypeScript bir ayrıştırıcı + eşleştiriciden oluşur ve birim testleriyle korunur. Tema, çeviri ve bileşenler tek kaynaktan gelir.

**Tech Stack:** Expo (güncel SDK), Expo Router, TypeScript (strict), zustand, i18next + react-i18next + expo-localization, @expo-google-fonts (Inter, Space Grotesk), react-native-svg, expo-linear-gradient, jest-expo.

**Spec:** `docs/superpowers/specs/2026-09-25-prototip-design.md`

- [ ] **Step 2: `parse.ts` yaz.** Algoritma sırası önemli; her eşleşen parça metinden silinir ki sonraki adım onu tekrar yakalamasın:
  1. **Normalleştir:** `text.toLocaleLowerCase('tr-TR')`, `’`→`'`.
  2. **Fiyat:**
     - Kalıp A (önce sembol): `/([€$₺])\s*(\d+(?:[.,]\d+)*)\s*(bin|k|milyon|million|mn)?/`
     - Kalıp B (sonra birim): `/(\d+(?:[.,]\d+)*)\s*(bin|k|milyon|million|mn)?\s*(tl|₺|lira|euro|eur|€|dolar|usd|\$)/`
     - Sayı çevirimi: `^\d{1,3}([.,]\d{3})+$` ise ayraçlar silinir, değilse `,`→`.` + `parseFloat`.
     - Çarpan: bin/k = 1e3, milyon/million/mn = 1e6.
     - Bağlam, eşleşmeden sonraki 14 karakterde aranır:
       - `civar|tutarında|around|about` → min = Math.round(0.85x), max = Math.round(1.15x)
       - `üstü|üzeri|en az|over|above|min` → min
       - diğer her durum → max
     - Ön bağlam: `up to|under|max` → max.
     - Para birimi eşlemesi: tl/₺/lira→TRY, euro/eur/€→EUR, dolar/usd/$→USD
  3. **Yıl:** `/\b(19[5-9]\d|20[0-4]\d)\b/`
     - Arka bağlam 16 karakter:
       - `sonra|üzeri|ve üstü|'?[td]en yeni|after|newer` → min
       - `önce|öncesi|before|older` → max
       - `model` ya da bağlamsız → min = max = yıl
     - Ön bağlam: `after|since` → min, `before` → max.
  4. **Boy:** `/(\d+(?:[.,]\d+)?)\s*(?:m\b|mt\b|metre\w*|meter\w*|metrelik)/`
     - Arka bağlam 12 karakter:
       - `kadar|altı|max` → max
       - `üstü|üzeri|fazla|over|above` → min
     - Ön bağlam: `up to|under|max` → max, `over|min` → min.
     - Bağlam yoksa min = n−1, max = n+1.
  5. **Ekipman** (bulunma sırasıyla, tekrarsız):
